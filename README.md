# Aniket Thakre — Software Engineer Portfolio

A responsive portfolio for Aniket Thakre, Senior Software Engineer. It presents his engineering background, selected fintech and telecommunications work, technical toolkit, experience, and contact details.

## View the deployed portfolio

You can see the live project here: [aniket-portfolio-work.vercel.app](https://aniket-portfolio-work.vercel.app/).

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run lint
npm run build
```

## Project files

- `app/page.tsx` — portfolio sections and career content
- `app/globals.css` — responsive layout and visual styling
- `app/layout.tsx` — page metadata
- `app/icon.svg` — AT favicon
- `public/aniket-thakre.jpg` — profile photo
- `public/resume.pdf` — résumé linked from the portfolio
