# Aniket Thakre — Portfolio

A responsive software engineering portfolio built with Next.js, TypeScript, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```

## Project structure

- `app/page.tsx` — portfolio content and sections
- `app/globals.css` — responsive styling
- `app/icon.svg` — AT favicon
- `public/aniket-thakre.jpg` — profile photo
- `public/resume.pdf` — downloadable résumé
